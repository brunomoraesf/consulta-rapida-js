Fundamentos de JavaScript

01 Variáveis

Variáveis armazenam valores que podemos usar durante a execução do programa.

const

Use quando a variável não será reatribuída.

const NOME = "Bruno";

Não podemos fazer:

NOME = "Carlos"; // Erro

let

Use quando o valor poderá mudar.

let vida = 100;
vida = 80;
vida = 50;

02 Tipos de valores

string

Representa texto.

let nome = "Bruno";
let classe = "Guerreiro";

number

Representa números inteiros ou decimais.

let vida = 100;
let velocidade = 10.5;

boolean

Representa apenas true ou false.

let jogadorVivo = true;
jogadorVivo = false;

03 null

Representa a ausência intencional de um valor.

let alvo = null;

Significa: "Neste momento, não existe um alvo."

Depois podemos atribuir um valor:

alvo = "Slime";

04 undefined

Significa que uma variável não possui um valor definido.

let nome;

console.log(nome);
undefined

Também acontece ao acessar uma propriedade que não existe:

const jogador = {
    nome: "Bruno"
};

console.log(jogador.vida);
undefined

05 typeof

typeof verifica o tipo de um valor.

let nome = "Bruno";
let vida = 100;
let vivo = true;

console.log(typeof nome);
console.log(typeof vida);
console.log(typeof vivo);
string number boolean

Podemos usar diretamente:

console.log(typeof "Bruno"); // string
console.log(typeof 100);     // number
console.log(typeof true);    // boolean
Atenção com null
console.log(typeof null) retorna "object". Isso é um comportamento histórico do JavaScript que nunca foi corrigido para não quebrar código existente. 
console.log(typeof null);
object
Bônus: typeof NaN também retorna "number". Ou seja, NaN é tecnicamente um valor numérico inválido.

06 Operadores

Os operadores são símbolos usados para realizar operações com valores. Nos exemplos abaixo, considere const a = 10; e const b = 5;.

Soma (+)

const c = a + b;

Soma o valor de a com o valor de b.

Subtração (-)

const c = a - b;

Subtrai o valor de b do valor de a.

Multiplicação (*)

const c = a * b;

Multiplica o valor de a pelo valor de b.

Divisão (/)

const c = a / b;

Divide o valor de a pelo valor de b.

Módulo (%)

const c = a % b;

O operador % retorna o resto da divisão.

const resultado = 10 % 3;

console.log(resultado);
1

Isso acontece porque 10 / 3 resulta em 3, com resto 1.

07 String + Number

Aqui existe uma pegadinha clássica. Quando usamos + com uma string, o JavaScript pode concatenar os valores.

let vida = 100;

console.log("Vida: " + vida);
Vida: 100

Mas:

console.log("10" + 5);
105

O 5 foi convertido para texto.

08 Number + Number

Quando os dois valores são números, ocorre uma soma normal.

console.log(10 + 5);
15

09 String + String

Duas strings são concatenadas.

console.log("10" + "5");
105

Não é uma soma matemática.

10 String - Number

Com -, o JavaScript tenta converter a string para número.

console.log("10" - 5);
5

Isso também acontece com * e /:

console.log("10" * 2); // 20
console.log("10" / 2); // 5

11 Quando a conversão não funciona

Se o texto não representa um número:

console.log("Bruno" - 5);
NaN

NaN significa Not a Number (não é um número).

12 Conversão de String para Number

Podemos converter explicitamente:

let valor = "10";

let numero = Number(valor);

console.log(numero);
10

Agora:

console.log(typeof numero);
number

13 Conversão de Number para String

Também podemos transformar um número em texto:

let vida = 100;

let texto = String(vida);

console.log(typeof texto);
string

14 Comparações

Os operadores de comparação são usados para comparar valores.

OperadorNomeExemploResultado
>maior que10 > 5true
<menor que5 < 10true
>=maior ou igual a10 >= 10true
<=menor ou igual a10 <= 10true
==igual, com conversão de tipo10 == "10"true
===estritamente igual10 === "10"false
!=diferente, com conversão de tipo10 != "10"false
!==estritamente diferente10 !== "10"true

== x ===

O == pode fazer conversão de tipo antes de comparar.

10 == "10"
true

Já o === compara o valor e o tipo.

10 === "10"
false
Boa prática: no JavaScript moderno, normalmente damos preferência ao === e ao !==, porque evitam conversões inesperadas.

15 Estruturas de decisão

if

O if significa basicamente: "Se essa condição for verdadeira, faça isso."

if (vida === 0) {
    console.log("O personagem desmaiou!");
}

Nesse exemplo, a mensagem será exibida somente se vida for exatamente igual a 0.

else

O else define o que acontece quando a condição do if for falsa.

if (vida > 0) {
    console.log("O personagem está vivo!");
} else {
    console.log("O personagem desmaiou!");
}

Aqui, se vida for maior que 0, o personagem está vivo. Caso contrário, o else será executado.

else if

O else if serve para verificar uma nova condição quando a anterior for falsa.

if (vida > 49) {
    console.log("O personagem está vivo!");
} else if (vida > 0) {
    console.log("O personagem está ferido!");
} else {
    console.log("O personagem está morto!");
}
  • Se vida for maior que 49 → personagem está vivo.
  • Se não for maior que 49, mas for maior que 0 → personagem está ferido.
  • Se nenhuma das duas condições for verdadeira → personagem está morto.

O JavaScript verifica as condições de cima para baixo e executa o primeiro bloco cuja condição seja verdadeira.

16 switch...case

O switch...case é usado quando queremos verificar várias possibilidades para um mesmo valor.

switch (classe) {
    case "Guerreiro":
        console.log("Você escolheu Guerreiro!");
        break;

    case "Mago":
        console.log("Você escolheu Mago!");
        break;

    case "Arqueiro":
        console.log("Você escolheu Arqueiro!");
        break;

    default:
        console.log("Classe inválida!");
}
  • O switch verifica o valor de classe.
  • O case representa cada possibilidade que queremos verificar.
  • O break faz o switch parar depois que o caso correspondente for executado.
  • O default será executado quando nenhum dos case corresponder ao valor.

17 while e do...while

Os laços de repetição (também chamados de loops) são usados quando queremos executar determinado código várias vezes.

while

O while significa basicamente: "Enquanto essa condição for verdadeira, faça isso."

while (vida > 0) {
    console.log("O monstro está vivo!");

    vida = vida - 10;
}

Enquanto vida for maior que 0, o código dentro do while continuará sendo executado. A cada repetição, vida diminui 10. Quando chegar a 0 ou menos, a condição fica falsa e o laço é encerrado.

O while verifica a condição antes de executar.

do...while

O do...while é parecido, mas o código é executado primeiro e a condição é verificada depois.

do {
    console.log("O monstro está vivo!");

    vida = vida - 10;
} while (vida > 0);

Nesse caso, o código dentro do do será executado pelo menos uma vez, mesmo que vida já seja 0.

Resumindo:
while → verifica a condição primeiro e depois executa.
do...while → executa primeiro e depois verifica a condição.

18 for

O for também é usado para repetição. É muito útil quando queremos controlar a repetição usando uma variável de controle.

for (let i = 0; i < 5; i++) {
    console.log("Ataque!");
}

Nesse exemplo, "Ataque!" será exibido 5 vezes.

O for possui três partes principais:

for (inicialização; condição; atualização) {
    // código que será repetido
}
  • let i = 0 → cria a variável e define seu valor inicial.
  • i < 5 → enquanto essa condição for verdadeira, o código continua sendo repetido.
  • i++ → aumenta o valor de i em 1 a cada repetição.

19 break

O break é usado para interromper um laço de repetição ou um switch.

for (let i = 0; i < 10; i++) {

    if (i === 5) {
        break;
    }

    console.log(i);
}

Quando i chegar a 5, o break interromperá o for.

0 1 2 3 4

20 continue

O continue é usado para pular a repetição atual e continuar com a próxima.

for (let i = 0; i < 5; i++) {

    if (i === 2) {
        continue;
    }

    console.log(i);
}

Quando i for 2, o continue fará o código pular aquela repetição.

0 1 3 4
A diferença:
break → para o laço completamente.
continue → pula apenas a repetição atual.

21 Arrays

Um array é uma estrutura usada para armazenar vários valores em uma única variável.

const personagens = ["Guerreiro", "Mago", "Arqueiro"];

Cada elemento possui uma posição, chamada de índice. O índice começa em 0.

console.log(personagens[0]);
Guerreiro
console.log(personagens[1]);
Mago

22 Métodos de Array

Arrays possuem vários métodos que facilitam o trabalho com listas de valores.

.push()

Adiciona um valor ao final do array.

personagens.push("Ladino");

.pop()

Remove o último valor do array.

personagens.pop();

.shift()

Remove o primeiro valor do array.

personagens.shift();

.unshift()

Adiciona um valor no início do array.

personagens.unshift("Paladino");

23 for...of

O for...of é usado para percorrer os valores de algo que pode ser iterado, como um array ou uma string.

const personagens = ["Guerreiro", "Mago", "Arqueiro"];

for (const personagem of personagens) {
    console.log(personagem);
}
Guerreiro Mago Arqueiro

Podemos pensar no for...of como: "Para cada valor dentro disso, faça isso."

24 for...in

O for...in é usado principalmente para percorrer as propriedades de um objeto.

const personagem = {
    nome: "Bruno",
    classe: "Guerreiro",
    nivel: 1
};

for (const propriedade in personagem) {
    console.log(propriedade);
}
nome classe nivel

Podemos também utilizar a propriedade para acessar seu valor:

for (const propriedade in personagem) {
    console.log(personagem[propriedade]);
}
Bruno Guerreiro 1
Forma simples de lembrar:
for...of → valores
for...in → propriedades / chaves

25 Funções

Funções são blocos de código criados para executar uma determinada tarefa.

function calcularDano(ataque, defesa) {
    const dano = ataque - defesa;

    if (dano < 0) {
        return 0;
    }

    return dano;
}

Podemos guardar o valor retornado:

const danoCausado = calcularDano(10, 3);

console.log(danoCausado);
7

Parâmetros

Os parâmetros são os valores que a função recebe.

function calcularDano(ataque, defesa) {
    return ataque - defesa;
}

Aqui:

  • ataque → primeiro parâmetro
  • defesa → segundo parâmetro

Quando chamamos calcularDano(10, 3), temos ataque = 10 e defesa = 3.

return

return devolve um valor para quem chamou a função.

function somar(a, b) {
    return a + b;
}

const resultado = somar(5, 10);

console.log(resultado);
15

Pense em return como: "Faça o cálculo e me entregue o resultado."

26 Escopo

Escopo define onde uma variável pode ser acessada.

const nome = "Bruno";

function mostrarNome() {
    console.log(nome);
}

mostrarNome();

A função consegue acessar nome porque nome está em um escopo externo.

Agora:

function criarPersonagem() {
    const nome = "Bruno";

    console.log(nome);
}

criarPersonagem();

console.log(nome);

O segundo console.log gera erro, porque nome foi criada dentro da função.

Regra simples

const nome = "Bruno";

function exemplo() {
    const idade = 30;

    console.log(nome);  // funciona
    console.log(idade); // funciona
}

console.log(nome);  // funciona
console.log(idade); // erro

Uma variável criada dentro de uma função normalmente pertence ao escopo daquela função.

Escopo de bloco

let e const também respeitam blocos { }.

if (true) {
    const vida = 100;

    console.log(vida); // funciona
}

console.log(vida); // erro

27 try...catch

O try...catch é usado para tratar erros que podem acontecer durante a execução do código.

try {
    console.log(nome);
} catch (erro) {
    console.log("Ocorreu um erro!");
}

Podemos pensar assim:

  • try → "Tente executar isso."
  • catch → "Se der erro, faça isso."

Também podemos acessar informações sobre o erro:

try {
    console.log(nome);
} catch (erro) {
    console.log(erro);
}

28 Objetos

Objetos permitem agrupar informações relacionadas.

const personagem = {
    nome: "Bruno",
    classe: "Guerreiro",
    nivel: 1,
    vida: 100,
    ataque: 10,
    defesa: 5
};

Aqui temos um único objeto contendo várias propriedades.

Podemos acessar uma propriedade usando .:

console.log(personagem.nome);
console.log(personagem.vida);
console.log(personagem.ataque);
Bruno 100 10

Alterando propriedades

Mesmo sendo const, podemos alterar propriedades do objeto:

const personagem = {
    nome: "Bruno",
    vida: 100
};

personagem.vida = 80;

console.log(personagem.vida);
80

Isso acontece porque const impede a variável de receber outro objeto, mas não impede a alteração das propriedades do objeto.

29 Métodos

Um método é uma função que pertence a um objeto.

const personagem = {
    nome: "Bruno",
    vida: 100,

    atacar() {
        console.log("O personagem atacou!");
    }
};

personagem.atacar();
O personagem atacou!

Pense assim:

Objeto
 ├── propriedades
 └── métodos

Exemplo:

const personagem = {
    nome: "Bruno",
    vida: 100,

    atacar() {
        console.log("Ataque!");
    }
};
  • nome e vida são propriedades.
  • atacar() é um método.

30 this

this permite que um método faça referência ao próprio objeto.

const personagem = {
    nome: "Bruno",
    vida: 100,

    mostrarNome() {
        console.log(this.nome);
    }
};

personagem.mostrarNome();
Bruno

Neste caso, this.nome significa: "O nome deste objeto."

Outro exemplo:

const personagem = {
    nome: "Bruno",
    vida: 100,

    receberDano(dano) {
        this.vida = this.vida - dano;
    }
};

personagem.receberDano(20);

console.log(personagem.vida);
80

O método modificou a própria vida do personagem.

31 Destructuring

Destructuring permite extrair valores de objetos ou arrays de maneira mais prática.

Objeto

const personagem = {
    nome: "Bruno",
    classe: "Guerreiro",
    nivel: 10
};

Sem destructuring:

const nome = personagem.nome;
const classe = personagem.classe;
const nivel = personagem.nivel;

Com destructuring:

const { nome, classe, nivel } = personagem;

Agora podemos usar:

console.log(nome);
console.log(classe);
console.log(nivel);

Pense assim: const { nome, classe } = personagem; significa "Pegue nome e classe de dentro desse objeto."

32 Destructuring de arrays

Também podemos fazer isso com arrays.

const personagens = ["Guerreiro", "Mago", "Arqueiro"];

const [primeiro, segundo, terceiro] = personagens;

console.log(primeiro);
console.log(segundo);
console.log(terceiro);
Guerreiro Mago Arqueiro
Atenção: nos arrays a ordem importa.

33 Spread ...

O operador spread (...) permite espalhar os elementos de uma estrutura.

const personagem = {
    nome: "Bruno",
    nivel: 10
};

const personagemAtualizado = {
    ...personagem,
    vida: 100
};

Agora:

console.log(personagemAtualizado);
{ nome: "Bruno", nivel: 10, vida: 100 }

O ...personagem espalhou as propriedades do objeto dentro do novo objeto.

Com arrays

const guerreiros = ["Bruno", "Carlos"];
const magos = ["Ana", "Julia"];

const personagens = [...guerreiros, ...magos];

console.log(personagens);
["Bruno", "Carlos", "Ana", "Julia"]

Pense: ... = "espalhe o conteúdo aqui."

34 Rest ...

O mesmo ... também pode ser usado para reunir vários valores.

function somar(...numeros) {
    console.log(numeros);
}

somar(10, 20, 30, 40);

O parâmetro ...numeros reúne os valores em um array.

[10, 20, 30, 40]

Spread x Rest

Apesar de usarem o mesmo ..., a função é diferente.

Spread — espalha valores:

const personagens = [...guerreiros];

Rest — reúne valores:

function exemplo(...valores) {
}
Forma simples de lembrar:
Spread → espalha
Rest → reúne

35 Classes

Classes são uma forma de criar estruturas para representar objetos semelhantes.

Por exemplo, vários personagens podem possuir: nome, vida, ataque, defesa e um método para atacar.

class Personagem {
    constructor(nome, vida, ataque, defesa) {
        this.nome = nome;
        this.vida = vida;
        this.ataque = ataque;
        this.defesa = defesa;
    }

    atacar() {
        console.log(`${this.nome} atacou!`);
    }
}

Agora podemos criar personagens:

const jogador = new Personagem("Bruno", 100, 10, 5);
const inimigo = new Personagem("Slime", 50, 8, 3);

Cada objeto possui seus próprios valores.

console.log(jogador.nome);
console.log(inimigo.nome);
Bruno Slime

constructor

O constructor é executado quando usamos new.

const jogador = new Personagem("Bruno", 100, 10, 5);

Os valores são enviados para:

constructor(nome, vida, ataque, defesa)

E então:

this.nome = nome;
this.vida = vida;
this.ataque = ataque;
this.defesa = defesa;

new

new cria um novo objeto baseado na classe.

const jogador = new Personagem(...);

Pense:

  • Classe = molde
  • Objeto = algo criado a partir desse molde

36 Métodos dentro de classes

Podemos colocar comportamentos dentro da classe.

class Personagem {
    constructor(nome, vida) {
        this.nome = nome;
        this.vida = vida;
    }

    receberDano(dano) {
        this.vida -= dano;
    }
}

Criando o personagem:

const jogador = new Personagem("Bruno", 100);

Aplicando dano:

jogador.receberDano(30);

console.log(jogador.vida);
70

Isso começa a deixar nosso sistema de RPG muito mais organizado.

37 Módulos

Quando um projeto cresce, não é interessante colocar todo o código em um único arquivo. Podemos dividir o projeto:

jogo/
│
├── personagem.js
├── combate.js
├── inimigos.js
└── main.js

Cada arquivo pode possuir uma responsabilidade.

export

Permite disponibilizar algo de um arquivo.

export function calcularDano(ataque, defesa) {
    const dano = ataque - defesa;

    if (dano < 0) {
        return 0;
    }

    return dano;
}

import

Permite utilizar algo de outro arquivo.

import { calcularDano } from "./combate.js";

Agora podemos utilizar:

const dano = calcularDano(10, 3);

console.log(dano);
Pense:
export → disponibiliza
import → traz para este arquivo

38 DOM

DOM significa Document Object Model.

Quando temos uma página HTML, o navegador transforma o HTML em uma estrutura que o JavaScript consegue acessar e modificar.

HTML:

<h1 id="titulo">Meu RPG</h1>

JavaScript:

const titulo = document.getElementById("titulo");

console.log(titulo);

Podemos alterar o texto:

titulo.textContent = "Meu RPG de JavaScript";

Agora o título da página muda.

Pense assim:

HTML
 ↓
DOM
 ↓
JavaScript consegue acessar/modificar

O DOM é o que vai permitir transformar nosso jogo que roda no console em um jogo que possui uma interface na página.

39 Selecionando elementos

Podemos usar:

document.getElementById("titulo");

Para buscar um elemento pelo id.

Também podemos usar:

document.querySelector("#titulo");

E:

document.querySelector(".personagem");

querySelector() permite buscar elementos usando seletores semelhantes aos do CSS.

40 Eventos

Eventos são acontecimentos na página. Por exemplo:

  • clique
  • teclado
  • mouse
  • formulário
  • etc.

Podemos detectar um clique:

HTML:

<button id="botao">Atacar</button>

JavaScript:

const botao = document.getElementById("botao");

botao.addEventListener("click", () => {
    console.log("O jogador atacou!");
});

Agora, sempre que o jogador clicar no botão, o código será executado.

Pense assim:
Evento: "Algo aconteceu."
addEventListener: "Quando isso acontecer, faça alguma coisa."

41 Evento aplicado ao nosso RPG

Podemos começar a transformar nosso combate em uma interface.

HTML:

<button id="botaoAtacar">Atacar</button>
<p id="vidaCriatura">Vida: 100</p>

JavaScript:

const botaoAtacar = document.getElementById("botaoAtacar");
const vidaCriatura = document.getElementById("vidaCriatura");

let vida = 100;

botaoAtacar.addEventListener("click", () => {
    vida -= 10;

    vidaCriatura.textContent = `Vida: ${vida}`;
});

Cada clique no botão reduz a vida da criatura. Isso já é o começo de transformar o nosso sistema de combate em um jogo de verdade no navegador.

42 Manipulação avançada do DOM

Já vimos como encontrar elementos:

const titulo = document.getElementById("titulo");

Agora podemos modificar várias características desses elementos.

Alterando texto

titulo.textContent = "RPG JavaScript";

Alterando HTML

titulo.innerHTML = "<strong>RPG JavaScript</strong>";
textContent trata o conteúdo como texto puro.
innerHTML permite inserir HTML — use com cuidado, pois pode abrir brechas de segurança se o conteúdo vier do usuário.

43 Alterando atributos

HTML:

<img id="imagemPersonagem" src="heroi.png">

JavaScript:

const imagem = document.getElementById("imagemPersonagem");

imagem.src = "slime.png";

Podemos alterar atributos usando:

elemento.setAttribute("atributo", "valor");

Exemplo:

imagem.setAttribute("src", "slime.png");

Também podemos ler um atributo:

console.log(imagem.getAttribute("src"));

44 Classes CSS pelo JavaScript

Podemos adicionar ou remover classes CSS.

HTML:

<p id="mensagem">O personagem está vivo!</p>

JavaScript:

const mensagem = document.getElementById("mensagem");

mensagem.classList.add("alerta");

Remover:

mensagem.classList.remove("alerta");

Alternar:

mensagem.classList.toggle("alerta");

O toggle funciona como um interruptor:

  • não possui a classe → adiciona
  • possui a classe → remove

Isso será muito útil para mudar visualmente o estado do jogo.

45 Criando elementos dinamicamente

Podemos criar elementos HTML usando JavaScript.

const novoParagrafo = document.createElement("p");

novoParagrafo.textContent = "O Slime apareceu!";

Mas ainda precisamos colocar esse elemento na página. Podemos usar:

document.body.appendChild(novoParagrafo);

Agora o parágrafo foi adicionado ao HTML.

Exemplo no RPG

const mensagem = document.createElement("p");

mensagem.textContent = "Um Slime apareceu!";

document.body.appendChild(mensagem);

Isso permite criar elementos conforme o jogo acontece.

46 Removendo elementos

Podemos remover um elemento:

mensagem.remove();

Isso é útil, por exemplo, para remover uma mensagem antiga ou retirar um inimigo da interface.

47 Eventos de teclado

Também podemos detectar teclas pressionadas.

document.addEventListener("keydown", (evento) => {
    console.log(evento.key);
});

Se o jogador apertar A, o console poderá mostrar:

a

Podemos verificar uma tecla específica:

document.addEventListener("keydown", (evento) => {
    if (evento.key === "Enter") {
        console.log("Enter pressionado!");
    }
});

Exemplo em jogo

document.addEventListener("keydown", (evento) => {
    if (evento.key === "a") {
        console.log("O personagem atacou!");
    }
});

Agora podemos começar a criar controles por teclado.

<input id="nomeJogador" type="text">

const nomeJogador = document.getElementById("nomeJogador");
const confirmar = document.getElementById("confirmar");

confirmar.addEventListener("click", () => {
    console.log(nomeJogador.value);
});

.value pega o conteúdo digitado. Se o jogador escrever Bruno, teremos nomeJogador.value com o valor "Bruno".

49 localStorage

O localStorage permite guardar informações no navegador.

localStorage.setItem("nomeJogador", "Bruno");

Agora podemos recuperar:

const nome = localStorage.getItem("nomeJogador");

console.log(nome);
Bruno

Removendo

localStorage.removeItem("nomeJogador");

Limpando tudo

localStorage.clear();
Pense assim:

Podemos guardar informações do personagem.

localStorage.setItem("nivel", "10");
localStorage.setItem("experiencia", "250");

Depois:

const nivel = localStorage.getItem("nivel");
const experiencia = localStorage.getItem("experiencia");

console.log(nivel);

Isso permite criar sistemas de:

  • salvar progresso
  • carregar personagem
  • guardar configurações
  • guardar pontuação
  • guardar preferências

51 JSON

Existe um problema: o localStorage trabalha principalmente com strings.

Então não podemos simplesmente fazer:

const personagem = {
    nome: "Bruno",
    vida: 100,
    nivel: 10
};

localStorage.setItem("personagem", personagem);

Precisamos transformar o objeto em JSON.

52 JSON.stringify()

JSON.stringify() transforma um valor JavaScript em uma string JSON.

const personagem = {
    nome: "Bruno",
    vida: 100,
    nivel: 10
};

const personagemJSON = JSON.stringify(personagem);

console.log(personagemJSON);
{"nome":"Bruno","vida":100,"nivel":10}

Agora podemos guardar:

localStorage.setItem("personagem", personagemJSON);

53 JSON.parse()

Quando recuperamos os dados:

const dados = localStorage.getItem("personagem");

eles voltam como string. Podemos transformar novamente em objeto:

const personagem = JSON.parse(dados);

Agora podemos fazer:

console.log(personagem.nome);
console.log(personagem.vida);
console.log(personagem.nivel);
Resumo do fluxo:
Objeto → JSON.stringify() → String JSON → localStorage → JSON.parse() → Objeto novamente

54 Salvando um personagem completo

const personagem = {
    nome: "Bruno",
    classe: "Guerreiro",
    nivel: 10,
    vida: 100,
    experiencia: 250
};

localStorage.setItem(
    "personagem",
    JSON.stringify(personagem)
);

Para carregar:

const dados = localStorage.getItem("personagem");

const personagemSalvo = JSON.parse(dados);

console.log(personagemSalvo);

Isso já é praticamente um sistema de save.

55 Promise

Uma Promise representa uma operação que pode terminar no futuro. Ela pode estar:

  • pendente (pending);
  • resolvida (fulfilled);
  • rejeitada (rejected).
const promessa = new Promise((resolve, reject) => {

    let sucesso = true;

    if (sucesso) {
        resolve("Operação realizada!");
    } else {
        reject("A operação falhou!");
    }

});

Podemos pensar em uma Promise como: "Estou tentando fazer alguma coisa. Quando terminar, aviso se deu certo ou errado."

56 .then()

O .then() define o que deve acontecer quando uma Promise for resolvida com sucesso.

promessa.then((resultado) => {
    console.log(resultado);
});

Podemos pensar: .then() → "Quando der certo, faça isso."

57 .catch() em Promises

O .catch() trata uma Promise que foi rejeitada.

promessa
    .then((resultado) => {
        console.log(resultado);
    })
    .catch((erro) => {
        console.log(erro);
    });

Podemos pensar:

  • .then() → se der certo.
  • .catch() → se der errado.

58 async

A palavra async é usada para declarar uma função assíncrona.

async function iniciarJogo() {
    console.log("Jogo iniciado!");
}

Uma função async sempre retorna uma Promise.

59 await

O await é usado dentro de uma função async para esperar uma Promise terminar antes de continuar.

async function iniciarJogo() {

    const resultado = await promessa;

    console.log(resultado);
}

Podemos pensar: await → "Espere essa operação terminar antes de continuar."

Normalmente, async e await são usados juntos com try...catch:

async function carregarJogo() {

    try {
        const resultado = await promessa;

        console.log(resultado);

    } catch (erro) {
        console.log(erro);
    }
}

60 fetch()

fetch() permite fazer requisições para buscar informações externas.

fetch("https://exemplo.com")

O resultado é uma Promise. Por isso podemos usar:

fetch("https://exemplo.com")
    .then((resposta) => {
        console.log(resposta);
    });

Ou, usando async/await:

async function carregarDados() {
    const resposta = await fetch("https://exemplo.com");

    console.log(resposta);
}

62 Transformando uma resposta em JSON

Quando usamos fetch, normalmente precisamos transformar a resposta em JSON.

async function carregarMonstro() {
    const resposta = await fetch("https://exemplo.com/monstro");

    const monstro = await resposta.json();

    console.log(monstro);
}

A sequência é:

fetch()
   ↓
resposta
   ↓
resposta.json()
   ↓
objeto JavaScript

63 Tratamento de erros com fetch

Como uma requisição pode falhar, podemos utilizar try...catch.

async function carregarMonstro() {
    try {
        const resposta = await fetch("https://exemplo.com/monstro");

        const monstro = await resposta.json();

        console.log(monstro);

    } catch (erro) {
        console.log("Não foi possível carregar o monstro.");
    }
}
Pense:
try → tente fazer a operação
catch → se der erro, trate o erro

64 Programação assíncrona

Algumas operações não terminam imediatamente. Exemplos:

  • buscar dados na internet
  • carregar arquivos
  • esperar respostas de servidores
  • algumas operações do navegador

JavaScript pode continuar executando enquanto essas operações acontecem. Por isso existem:

  • Promise
  • .then()
  • .catch()
  • async
  • await

A forma que geralmente vamos preferir nos nossos projetos será:

async function exemplo() {
    try {
        const resultado = await algumaOperacao();

        console.log(resultado);

    } catch (erro) {
        console.log(erro);
    }
}

65 Orientação a objetos

Já começamos a trabalhar com objetos e classes. Orientação a objetos é uma forma de organizar o código pensando em objetos, dados e comportamentos.

Personagem
 ├── nome
 ├── vida
 ├── ataque
 ├── defesa
 ├── atacar()
 └── receberDano()
Criatura
 ├── nome
 ├── vida
 ├── ataque
 ├── defesa
 ├── atacar()
 └── receberDano()

Classes podem ajudar a representar essas entidades.

66 Herança

Uma classe pode herdar características de outra.

class Personagem {
    constructor(nome, vida) {
        this.nome = nome;
        this.vida = vida;
    }

    receberDano(dano) {
        this.vida -= dano;
    }
}

Podemos criar uma classe derivada:

class Guerreiro extends Personagem {
    constructor(nome, vida, espada) {
        super(nome, vida);

        this.espada = espada;
    }
}

Criando:

const guerreiro = new Guerreiro(
    "Bruno",
    100,
    "Espada de Ferro"
);

O guerreiro possui as características herdadas de Personagem.

extends

class Guerreiro extends Personagem

Significa: Guerreiro herda de Personagem.

super()

super(nome, vida);

Chama o constructor da classe pai.

67 Composição

Nem sempre precisamos usar herança. Também podemos montar objetos combinando diferentes partes.

Imagine:

const arma = {
    nome: "Espada",
    dano: 15
};

E:

const personagem = {
    nome: "Bruno",
    vida: 100,
    arma: arma
};

Agora o personagem possui uma arma. Podemos acessar:

console.log(personagem.arma.nome);
console.log(personagem.arma.dano);
Espada 15

Isso é uma forma de composição: um objeto é formado por outros objetos.

★ Resumo Geral

Tudo o que foi visto no guia, organizado por categoria.

📦 Variáveis

  • const → não será reatribuída.
  • let → poderá ter seu valor alterado.

🔤 Tipos de valores

  • string → texto.
  • number → inteiros ou decimais.
  • boolean → true ou false.
  • null → ausência intencional de valor.
  • undefined → valor não definido.
  • NaN → resultado que não representa um número válido.
  • typeof → revela o tipo (cuidado: typeof null é "object").

🔄 Conversão de tipos

  • Number(valor) → string para número.
  • String(valor) → número para string.
  • "10" + 5 → "105" (concatena).
  • "10" - 5 → 5 (converte para número).
  • "Bruno" - 5 → NaN.

➕ Operadores matemáticos

  • + → soma.
  • - → subtração.
  • * → multiplicação.
  • / → divisão.
  • % → resto da divisão.

⚖️ Comparações

  • > → maior que.
  • < → menor que.
  • >= → maior ou igual.
  • <= → menor ou igual.
  • == → igual, com conversão de tipo.
  • === → estritamente igual (valor + tipo).
  • != → diferente, com conversão de tipo.
  • !== → estritamente diferente.

🔀 Estruturas de decisão

  • if → verifica uma condição.
  • else if → verifica outra condição caso a anterior seja falsa.
  • else → executa quando as condições anteriores forem falsas.
  • switch...case → verifica várias possibilidades para um mesmo valor.
  • break → encerra um case.
  • default → executado quando nenhum case corresponde.

🔁 Repetições

  • while → repete enquanto a condição for verdadeira (verifica antes).
  • do...while → executa primeiro e verifica a condição depois.
  • for → repetição com inicialização, condição e atualização.
  • for...of → percorre valores.
  • for...in → percorre propriedades/chaves.

⏯️ Controle das repetições

  • break → interrompe o laço completamente.
  • continue → pula apenas a repetição atual.

📚 Arrays

  • push() → adiciona no final.
  • pop() → remove do final.
  • shift() → remove do início.
  • unshift() → adiciona no início.
  • forEach() → executa algo para cada elemento.
  • map() → cria um novo array transformando os elementos.
  • filter() → cria um novo array filtrando os elementos.
  • find() → encontra o primeiro elemento que atende à condição.

⚙️ Funções

  • function → declara uma função.
  • parâmetros → valores que a função recebe.
  • return → devolve um valor para quem chamou a função.

🧭 Escopo

  • Variáveis criadas dentro de funções pertencem àquele escopo.
  • let e const respeitam blocos { }.
  • Escopos internos acessam escopos externos — o contrário não acontece.

🧱 Objetos

  • objeto → agrupa informações relacionadas.
  • propriedades → dados dentro do objeto.
  • métodos → funções que pertencem ao objeto.
  • this → referência ao próprio objeto.
  • const não impede alterar propriedades do objeto.

📦 Destructuring

  • const { nome } = obj; → extrai valores de objetos.
  • const [primeiro] = array; → extrai valores de arrays (a ordem importa).

🌀 Spread / Rest

  • ... (spread) → espalha valores.
  • ... (rest) → reúne valores em um array.

🏗️ Classes

  • class → cria um molde para objetos.
  • constructor → executado ao usar new.
  • new → cria um objeto a partir da classe.
  • métodos → comportamentos dentro da classe.

🧩 Orientação a objetos

  • Herança → uma classe herda características de outra (extends / super()).
  • Composição → um objeto é formado por outros objetos.
  • Organização → separar responsabilidades em arquivos e módulos.

📦 Módulos

  • export → disponibiliza algo de um arquivo.
  • import → traz algo de outro arquivo.

🌐 DOM

  • getElementById() → busca elemento pelo id.
  • querySelector() → busca elemento por seletor CSS.
  • textContent → altera o texto de um elemento.
  • innerHTML → altera o HTML interno de um elemento.
  • setAttribute() → altera atributos.
  • getAttribute() → lê atributos.
  • classList.add() → adiciona classe CSS.
  • classList.remove() → remove classe CSS.
  • classList.toggle() → alterna classe CSS.
  • createElement() → cria um novo elemento.
  • appendChild() → adiciona elemento na página.
  • remove() → remove elemento da página.

🖱️ Eventos

  • addEventListener() → escuta um evento.
  • "click" → evento de clique.
  • "keydown" → evento de tecla pressionada.
  • evento.key → tecla pressionada.
  • .value → valor digitado em um formulário.

💾 Armazenamento

  • localStorage.setItem() → guarda um valor.
  • localStorage.getItem() → recupera um valor.
  • localStorage.removeItem() → remove um valor.
  • localStorage.clear() → limpa tudo.

🗂️ JSON

  • JSON.stringify() → transforma objeto em string JSON.
  • JSON.parse() → transforma string JSON em objeto.

🚨 Tratamento de erros

  • try → tenta executar.
  • catch → trata o erro.
  • erro → objeto com informações sobre a falha.

⏳ Código assíncrono

  • Promise → representa uma operação que será concluída no futuro.
  • .then() → executa quando a Promise é resolvida.
  • .catch() → trata uma Promise rejeitada.
  • async → declara uma função assíncrona (sempre retorna Promise).
  • await → espera uma Promise terminar antes de continuar.

🌍 fetch / APIs

  • fetch(url) → faz requisições para buscar dados externos.
  • resposta.json() → transforma a resposta em objeto JavaScript.
  • API → sistema que disponibiliza dados ou funcionalidades.
  • try/catch → trata falhas na requisição.

🧠 Mentalidade

  • Não decorar → entender qual ferramenta usar para cada problema.
  • Problema → ferramenta → variável, if, loop, array, objeto, função, classe, evento, DOM, localStorage, fetch, módulos.
  • Praticar → usar o RPG como laboratório para fixar cada conceito.
