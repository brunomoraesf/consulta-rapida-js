## ✨ Sobre

Este repositório é um **guia de consulta rapida de JavaScript** criado para quem está começando.

Em vez de despejar conceitos soltos, o material foi **organizado na ordem em que faz sentido aprender**: primeiro os fundamentos, depois controle de fluxo, arrays, funções, objetos, classes, DOM, eventos, armazenamento e, por fim, código assíncrono.

## 🎯 O que você encontra aqui

- 📚 **67 tópicos** resumidos e organizados em ordem de aprendizado
- 🧠 **Resumo geral** sucinto organizado em cartões simples
- 🔎 **Busca inteligente** que ignora acentos e prioriza títulos
- 🌗 **Tema escuro** confortável para longas sessões de estudo
- 📱 **Responsivo** — funciona bem no celular, tablet e desktop
- 💡 **Modal "Regra principal do estudo"** que ajuda a pensar *qual ferramenta usar* para cada problema
